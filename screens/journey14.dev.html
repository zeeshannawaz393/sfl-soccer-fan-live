Soccer Fan Live · Journey 14 — Manager Console

The Dugout Command Center

The club's operational HQ — monitor performance, recruit Fans, claim rewards, manage the squad, and process transfers & loans. Built on one rule: a Manager can invite but never own a Fan. Invitations need acceptance, transfers/loans need consent, and every decision is audit-logged. Dark dugout theme, scoreboard numerals, gold = value, lime = approval, amber = pending consent, coral = rejection.
